OpenSky Terrain

A data standard and a verified reference toolchain that turns crowdsourced boat soundings into game-ready bathymetric terrain tiles — with contours a fisherman can trust to the fathom. Built for OpenSkyFlight-class Three.js platforms, around Sitka Sound, Alaska.

Spec v0.1 + v0.2 amendments Verification suite 10 / 10 Reference code Python + TypeScript three-tile loader spike PASS

The finding that started it

Sitka's tide station is 9451600.

A widely copied research pack called NOAA station 9452210 “Sitka” in its spec, its generator, its ground truth, and all four of its audit implementations. That station is Juneau. Sitka is 9451600; the number in the pack's bake memo, 9451054, is Port Alexander. Three station IDs, three different harbours — and every tide correction downstream of the wrong one is silently wrong with it. Verified against the NOAA/NCEI CO-OPS station tables; the corrections are published in this repository.

And the plateau that wasn't the algorithms' fault

Four independent tide-correction implementations plateaued at ≈ 0.40 fathoms of disagreement on a test shoal. The cause was not the math. The synthetic tide table ended at 23:54 while the sounding tracks ran to 03:37 — and the interpolator silently clamped ~300 out-of-range soundings to the last tide value. The fix is an invariant, now written into the spec: tide tables must cover the full timestamp range of every sounding file; never clamp — exclude and flag.

The pipeline

STAGE 1CSB correction Joint fit: one shared tide coefficient + per-vessel transducer offsets, fitted — never sign-assumed.
STAGE 2COPC archive Corrected soundings stored as COPC/LAZ at ~20× compression, WGS84 in / out.
STAGE 3Fusion grid Survey preferred, fleet second, gaps interpolated — every cell carries its source.
STAGE 4Tile bake Quantized-mesh tiles in a local ENU frame, per-vertex bottom-type (ext 5) and confidence (ext 6).
STAGE 5Runtime TypeScript decoder + LOD selector bind contour intervals to honest mesh error. Runtime owns the tide.

Format decisions

  • Quantized-mesh-1.0 over Terrarium PNG — per-vertex data carriage, true triangulation, LOD error binding.
  • Local ENU frame per pack — Web Mercator rejected at 57°N; meters inside, fathoms on display.
  • Bake is static MLLW seafloor — exaggeration is render-only and can never leak into physics.
  • Decoders must skip unknown extensions by length — a widely used NASA loader was source-verified to break on them; ours doesn't.

Run the receipts

git clone https://github.com/SuperInstance/opensky-terrain
cd opensky-terrain
python checks/run_all.py        # 10 passed, 0 failed

Requires Python 3.11+ (numpy, pandas) and Node 22+. The COPC check uses a PDAL binary when present and skips cleanly without one.

Status

Specification v0.1 with v0.2 amendments; reference implementations verified end-to-end on synthetic data. The first audit on real soundings awaits access to the local data machine — fleet data stays private, and only synthetic data is ever published here. One design question is still open, with the decision packet in the spec: pack extent vs a curved sea surface (at a 90×50 km pack's corners, the earth falls 208 m out from under a flat one).
